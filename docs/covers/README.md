# 영상 커버 원본

인스타 릴스 커버의 **작업 원본**이다 (2160×3840 / 1080×1920). 사이트는 이 파일들을
서빙하지 않는다 — 카드와 공유 카드가 쓰는 건 `public/videos/<slug>.jpg` 쪽이다.

`public/` 에 두면 안 되는 이유는 그 디렉토리가 통째로 컨테이너에 실려 나가기 때문이다.
아무도 요청하지 않는 12MB 를 매 배포마다 같이 나르게 된다. 원본은 다시 잘라야 할 때만
필요하므로 `docs/brand/` 의 아이콘 원본과 같은 자리에 둔다.

인스타 편의 썸네일을 갈아끼울 때:

1. 여기서 원본을 열어 1200×630 근처로 잘라 `public/videos/<slug>.jpg` 로 저장
2. MDX frontmatter 의 `thumbnail:` 이 그 경로를 가리키는지 확인

`npm run thumbs` 는 인스타 편에는 쓸 수 없다 — 로그인 벽에 막혀 og:image 를 못 읽는다
(CLAUDE.md 6번). 그래서 이 폴더가 있다.
