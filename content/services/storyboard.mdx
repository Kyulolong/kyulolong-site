  릴스·쇼츠 콘티를 보드로 그려주는 웹앱을 만들어줘.

  쓰는 흐름:
  - 콘티 글을 통째로 붙여넣는다 (챗봇으로 미리 써온 것)
  - 붙여넣으면 컷 단위로 쪼개서 9:16 세로 카드로 늘어놓는다
  - 카드마다 컷 번호, 화면에 뭐가 보이는지, 자막이 들어간다

  중요한 제약이 하나 있어:
  - 글은 절대 만들지 마. 콘티 글 생성은 이 앱의 일이 아니야
  - 붙여넣은 글을 쪼개고 그림과 보드만 책임진다
  - 이렇게 역할을 자르면 API 키도 비용도 필요 없어진다. 그 선을 지켜줘

  그림:
  - 기본값은 브라우저 안에서 그리는 러프 스케치 (사람 실루엣, 프레임, 화살표 수준)
  - 설정에서 이미지 생성 모델을 켤 수 있게 하되, 호출이 실패하면
    조용히 러프 스케치로 되돌아가야 해. 그림 하나 때문에 콘티 전체가 멈추면 안 된다

  마지막에 보드 전체를 이미지 한 장이나 PDF로 내보내기.

릴스 하나 만들 때마다 콘티를 손으로 쪼개는 데 30분씩 걸렸다.
컷을 나누고, 각 컷에 뭘 찍을지 적고, 자막을 붙이는 일 말이다.

**글은 만들지 않는다.** 쓰던 챗봇으로 콘티 글을 만들어 붙여넣으면,
여기서는 그림과 보드만 책임진다. 역할을 이렇게 자르니 API 키도 비용도 0이 된다.

그림은 기본값이 브라우저 안에서 그리는 러프 스케치다. 진짜 그림이 필요하면
설정에서 이미지 모델로 바꾼다. 모델 호출이 실패해도 러프 스케치로 되돌아가서
콘티가 중간에 끊기지 않는다.
